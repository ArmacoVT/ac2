# Публичен сайт ac2.bg — какво е направено и как се пуска

## Структура
- `index.html` — публичният сайт (начало, програма, събитие, ресторант/меню/вечери/брънч, членство, за AC²/екип/наеми, Arcus College, App, контакти, правна информация). Хеш адреси: `#/program`, `#/program/gallery`, `#/event/<id>`, `#/restaurant/menu`, …
- `app/index.html` — членското приложение (същото, което беше на корена; вече на **ac2.bg/app/**).
- `brand.js` — логото и анимираната лента (общи за двете).
- `db.js` — `PUB_DEFAULTS` (текстове по подразбиране) + методи за публичния сайт.
- `supabase/sql/public_site.sql` — база: `events.pub`, публично четене, съобщения, нюзлетър, роля „редактор".
- `supabase/functions/public-forms/index.ts` — контактна форма (→ имейл) и нюзлетър.
- `sw.js` — v230.

## Стъпки за пускане (в този ред)
1. **Supabase → SQL Editor** (проект `twcxfqgknhqicxqghcrx`): пусни `supabase/sql/public_site.sql`.
2. **Supabase → Edge Functions**: създай `public-forms`, копирай `supabase/functions/public-forms/index.ts`, **Verify JWT: OFF**. Secrets: вече има `TURNSTILE_SECRET_KEY` и SMTP_*; по избор добави `CONTACT_TO` (по подразбиране welcome@ac2.bg).
3. **Supabase → Authentication → URL Configuration**: Site URL → `https://ac2.bg/app/`; Redirect URLs → добави `https://ac2.bg/app/**`. (Старите линкове към корена също се пренасочват към /app/ автоматично.)
4. **GitHub Desktop**: sync-to-github.bat → push. Провери: ac2.bg (сайт), ac2.bg/app/ (вход), ac2.bg/admin.html.
5. **Админ панел → Публичен сайт**: попълни адрес, телефон, работно време, социални мрежи, карта (Google Maps → Споделяне → Вграждане → само адреса от `src`), слайдове, снимки. Запази.
6. **Админ панел → Събития**: за всяко събитие, което трябва да е публично — отметка „Показвай на публичния сайт" + направление + категория.
7. **iOS приложение** (`mobile-setup/capacitor.config.json`): смени `server.url` на `https://ac2.bg/app/` при следващата версия.
8. **Аналитика** (по желание): в `config.js` сложи `GA_ID` (G-…) и/или `META_PIXEL_ID`. Банерът за бисквитки се показва само ако има поне един ID; скриптовете се зареждат само след „Приемам".

## Роля „редактор"
```sql
update public.profiles set role = 'editor'
where id = (select id from auth.users where email = 'адрес@пример.bg');
```
Редакторът вижда в админ панела само: Събития, Публичен сайт, Вход в приложението, Съобщения.

## Нюзлетър
Абонатите се пазят в `newsletter_subscribers` (със съгласие и дата). Админ панел → Съобщения → „Експорт CSV" за Mailchimp. Директна връзка с Mailchimp — по-късно, ако се реши.

## Проверка след пускане
- ac2.bg: интро с логото → начална страница; BG/EN; меню с подменюта; мобилно меню (бургер).
- Контакти: формата минава Turnstile и пристига на welcome@ac2.bg + в Админ → Съобщения.
- Нюзлетър: записва се, вижда се в Админ → Съобщения.
- Събитие с отметка „на сайта" се вижда в Програма; „Билети" води към ac2.bg/app/#event/… (или външния линк).
- ac2.bg/app/: входът и приложението работят както преди; линк за покана/нова парола отваря /app/.
